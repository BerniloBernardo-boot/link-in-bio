# Bernilo Links

Uma página pessoal para reunir os meus principais links num só lugar, com um visual retro, minimalista e inspirado em tons naturais.

## Sobre o projeto

Este projeto funciona como a minha página de links pessoais, facilitando o acesso ao meu portfólio, GitHub, LinkedIn e YouTube através de um único endereço.

## Tecnologias

- HTML5
- CSS3

## Design

## Executar localmente

1. Clona o repositório.
2. Abre a pasta do projeto.
3. Abre o ficheiro `index.html` no navegador.
